# Block puzzle: one line or two?

Work ID: NEWGAMES-BLOCK-CLEAR-TRADEOFF

Added an original bonus exercise to the existing block guide. Both first moves are legal on this teaching board. A clears row 2 and column A but leaves no legal square placement. B clears only column C but opens exactly one square at C3, D3, C4 and D4. The starting board has no legal square. This is a lesson about fitting the next visible piece, not an assertion about scores or optimal moves in a real game.

The existing closed-answer and result-board components are reused. The update directory and practice finder link to the bonus, and the feed describes the revision. Original guide URL, publication date, existing exercises, homepage, styles and site configuration are unchanged. No new game, scripts, analytics or third-party claims.
